I was watching my boss give a talk at [Merge PHP](https://mergephp.com) the other night, and one thing that initially stood out was when he mentioned that 
a kind of unspoken agreement was in place when it came to coding and reviewing. The agreement was that we as engineers were capable of
reviewing code at roughly the same speed it was written. Thats because a human was on both sides of the equation. I, as an engineer, can only
type so fast and I, as the reviewer, can only read so fast. It was a nice balance. We weren't overwhelemed with the amount of code
available for us to review. 

Then tools such as Claude burst on to the scene and flipped the paradigm upside so fast that we had a deluge of pull request to review.
